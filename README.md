# Video a partir de uma imagem

## 📒 Descrição
Criei uma imagem a partir de uma foto, e pedi para a IA criar um video

## 🤖 Tecnologias Utilizadas
Gemini

## 🧐 Processo de Criação
Faça com que a imagem fale o seguinte texto:
"Aooo moçada... Compramos e vendemos boi para cocho, vaca e boi gordo, novilhas pesadas, vaca para charque! Chaaaamaaaa!"
Faça com que a pessoa da imagem fale andando com um tom descontraido e amigavel 

## 🚀 Resultados
Video em anexo

## 💭 Reflexão (Opcional)
Foi bem legal e divertido
